# 4 Inch 480x480

The WaveShare ESP32-S3 4 Inch 480x480 screen module is used primarily in deployments where the user needs to see more information than the standard CYD can provide.



This screen is ideal for multi-channel applications.



For wiring, it is meant to connect to the UART test points in the top left corner of the board. To prevent interference, this requires the RS-485 controller (U7) to be removed.
